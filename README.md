# NovaPay - Payment Infrastructure for the Internet

A modern SaaS payment platform landing page built with Next.js 16, TypeScript, and Tailwind CSS v4.

## Live Demo

[novapay-landing-weld.vercel.app](https://novapay-landing-weld.vercel.app)

## Features

- Dark theme with indigo/violet gradient accents
- Glass-morphism card effects
- Dot pattern hero background
- Smooth scroll navigation
- Code preview snippet showcase
- 3-tier pricing section
- Testimonials carousel
- Responsive mobile-first design
- Custom CSS animations
- Lucide React icons throughout

## Sections

1. Sticky navigation with CTA
2. Hero with API code preview
3. Trusted by logos strip
4. 6-feature grid with icons
5. How it works (3 steps)
6. Pricing tiers (Starter / Growth / Enterprise)
7. Integration partners
8. Customer testimonials
9. Email signup CTA
10. Multi-column footer

## Tech Stack

- **Framework:** Next.js 16.1.6 (App Router, Turbopack)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **Deploy:** Vercel

## Getting Started

```bash
npm install
npm run dev
```
